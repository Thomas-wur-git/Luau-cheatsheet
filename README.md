# Lua(u) cheatsheet

This is a cheatsheet, used as a reference file, (mainly) for learning lua's syntax, and having a good overview of the language. It wasn't made as a tutorial (to avoid it being way too long), but still contains explanations. This cheatsheet presupposes knowledge of programming terms, and programming fundamentals, so it's aimed at beginner-average scripters. For complete beginners, it could still be useful, but as a complement to other tutorials and outside ressources. Search what different terms mean, ask an ai to explain in more depth one of the concepts, etc

This cheatsheet was written with luau and lua 5.1 in mind. It contains mentions of runtimes and Roblox, but was written with standalone use in mind

The files can be run with the [lune](https://github.com/lune-org/lune) runtime. It may work with other luau runtimes (such as [zune](https://zune.sh/) or [lute](https://github.com/luau-lang/lute)), though I did not test it
